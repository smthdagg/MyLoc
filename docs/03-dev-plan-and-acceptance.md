# MyLoc 开发计划与验收标准（v0.3）

## 1. 架构
```
SwiftUI UI ─ Domain(状态机/路线引擎/坐标转换) ─ Engine 协议 ─┬ RealEngine → Rust(idevice) xcframework
                                                          └ MockEngine（模拟器/单测）
Storage: Keychain(配对) / UserDefaults(偏好、收藏、历史、会话记录)
```
单体 App，无 Extension；隧道用外部 LocalDevVPN。目录：`App/ Domain/ Engine/ Storage/ Rust/ docs/ scripts/`。

## 2. 开发规则
1. 先 M0 预研出结论，再动 M1；每个预研写一页结论到 `docs/research/`。
2. 所有 Rust 调用经 `Engine` 协议；UI 不直接依赖 FFI。
3. 纯逻辑（状态机、路线推进、坐标转换、配对解析、诊断脱敏）必须有单测，覆盖率目标 ≥ 80%。
4. 每个里程碑末：真机验证 → 更新 AC 结果表 → 更新"已知限制"。
5. 日志禁止出现坐标、配对内容、PIN；用统一 `Log` 封装并单测脱敏。
6. 独立实现：每个模块附"设计依据"（仅 idevice 文档/Apple 文档/协议事实）。

## 4. 验收标准
通用：每条在真机（iOS 26.x）执行，结果写入 `docs/test-report.md`，记录日期/设备/系统版本/通过与否/证据。

### 4.1 里程碑验收
| 编号 | 验收项 | 步骤 | 通过判据 |
|---|---|---|---|
| AC-01 | 安装启动 | 侧载安装，冷启动 5 次 | 无崩溃，引导页可见 |
| AC-02 | 配对导入 | 导入有效文件；再导入损坏/空/错类型文件 | 有效→"就绪"；无效→明确报错且不入 Keychain |
| AC-03 | 固定写入 | 选点开始，用系统地图与本 App 读数对比 | 读回与目标偏差 < 5 m（考虑坐标转换） |
| AC-04 | 会话改点 | 会话中连续改点 10 次 | 每次 ≤ 1 s 生效，日志无重连 |
| AC-05 | 停止恢复 | 停止并恢复 | 不再写入；有信号时回到真实位置（≤ 60 s） |
| AC-06 | 后台保持 | 锁屏/切 App 10 分钟 | 位置保持不变 |
| AC-07 | 网络切换 | Wi-Fi↔蜂窝、开关飞行模式 | 自动恢复或给出明确提示 ≤ 15 s |
| AC-08 | 异常恢复 | 会话中杀进程，重启 | 出现恢复提示，四选项均可用，不自动执行 |
| AC-09 | 步行路线 | 100 m / 1 km 路线，三档配速 | 用时与配速偏差 ≤ 5%；暂停/继续/反向/结束正确 |
| AC-10 | 诊断脱敏 | 生成诊断文本，正则扫描 | 无坐标、密钥、PIN、设备名 |
| AC-11 | 无网络上报 | 抓包 30 分钟全流程 | 仅有 Apple/MapKit 系统域名流量，无 App 自发请求 |
| AC-12 | 稳定性 | 固定 30 分 + 路线 30 分，连续 60 分 | 无崩溃，设备崩溃日志无本 App 条目，内存 < 150 MB |

### 4.2 补充验收
| 编号 | 验收项 | 通过判据 |
|---|---|---|

### 4.3 完成定义（DoD）
单个任务完成 = 代码合入 + 单测通过 + 无新增编译警告 + 对应 AC 有记录 + 文案已入 String Catalog。
版本发布 = 该里程碑 AC 全过 + 已知限制更新 + 自签 IPA 可安装。

## 5. 模型建议
我无法查看你环境里的完整模型列表，只能按任务类型给建议；以你界面里实际可选的为准。

| 阶段 | 建议 | 理由 |
|---|---|---|
| M0 预研、Rust FFI、协议、后台保活、坐标系 | **你选择里最强的推理/编码模型**（高思考档） | 跨语言、协议细节、需要读文档和排查真机问题，错误成本高 |
| Swift UI、状态机、单测、收藏历史、设置 | 当前模型（Claude Sonnet 5.5 Medium）足够 | 模式化代码，反馈快，成本低 |
| 文档整理、文案、本地化、测试报告 | 轻量/快速模型 | 低风险批量工作 |
| 代码评审与洁净度检查（M 末） | 强模型 | 需要全局一致性与相似度判断 |

实操建议：M0 和 T-102（Rust 引擎）用强模型；其余可保持当前模型，遇到真机排障或卡住 2 次以上再切强模型。
