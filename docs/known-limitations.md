# MyLoc 已知限制清单

1. **免费 Apple ID 签名限制（7 天过期）**：因无付费开发者账号，侧载签名每 7 天需重新签名；同一 Apple ID 活跃侧载 App 数量受 Apple 限制（通常 3 个）。
2. **无内置隧道扩展**：免费账号无法使用 NetworkExtension（Packet Tunnel）entitlement，因此 MyLoc 为单体 App，隧道完全依赖外部 LocalDevVPN。
3. **后台保活受系统调度影响**：采用 `UIBackgroundModes`（`location` + `audio`）方案维持后台写入，但在极端低电量或系统内存紧张时仍可能被挂起；异常退出后再次打开会弹出恢复提示（不自动执行）。
4. **中国大陆坐标系偏移**：内置粗略多边形判断中国大陆（排除港澳台），提供 GCJ-02 ↔ WGS-84 自动转换开关；边界数公里内建议按真机实测情况在设置中核对。
5. **iOS 27 设备端发起配对**：当前版本仅支持导入配对文件，iOS 27 新配对方式留待后续版本预研。
6. **GPX 导入限制**：仅支持单段（单个 `<trkseg>`）GPX 1.1 文件，多段 GPX 会被明确拒绝。
